Coherence's own cases, one form to a case, each with the whole tree the patched grammar must read it as. Kept here,
out of coherence.patch, so the patch has no way to rewrite what it is held to: build-phase.sh runs them with
tree-sitter test beside upstream's corpus, and compare.mjs holds the bundled parsers to each tree and each intended
difference to the cases it names. The forms the patch fixes, and forms beside them it must leave as the stock grammar
reads them.
