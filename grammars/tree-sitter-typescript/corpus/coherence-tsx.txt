Coherence's own cases for the TSX grammar alone (a file named *-tsx.txt is read by it alone), one form to a case, each
with the whole tree the patched grammar must read it as. Kept out of coherence.patch, as coherence.txt is.

Coherence: a bare ampersand in JSX text
==========================================

const a = <p>Read & write</p>;

  (lexical_declaration
    (variable_declarator
      (identifier)
      (jsx_element
        (jsx_opening_element
          (identifier))
        (jsx_text)
        (jsx_closing_element
          (identifier))))))
